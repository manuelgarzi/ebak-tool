Angefangene Beurteilungen

PDFs der Studierenden und eigene Zwischenstände öffnen Sie im neuen Zugang wie gewohnt über «Konzept öffnen».

Eine Beurteilung, die nur in Ihrem Browser gespeichert ist, zieht nicht automatisch mit um. So übernehmen Sie sie:

  1. Öffnen Sie im gleichen Browser den bisherigen eBAK-Zugang und melden Sie sich an.
  2. Öffnen Sie das Konzept unter «Auf diesem Gerät gespeichert» und klicken Sie auf «Zwischenstand speichern». Sie erhalten eine PDF.
  3. Öffnen Sie den neuen eBAK-Zugang und wählen Sie diese PDF unter «Konzept öffnen».

Der bisherige Zugang wird demnächst abgeschaltet. Bitte beurteilen Sie dort keine Konzepte mehr.
