Das Konzept-Tool hat eine neue Adresse

Bitte verwenden Sie ab sofort die neue Adresse und passen Sie Ihre Lesezeichen an.

Zum Konzept-Tool

https://ebak.idibphsg.ch/

Haben Sie hier schon an Ihrem Konzept gearbeitet?

PDFs aus dem Tool (Zwischenstand, Einreichung, Rückmeldung) öffnen Sie im neuen Tool wie gewohnt über «Datei öffnen».

Ein Entwurf, der nur in Ihrem Browser gespeichert ist, zieht nicht automatisch mit um. So übernehmen Sie ihn:

  1. Öffnen Sie im gleichen Browser die bisherige Version des Tools.
  2. Öffnen Sie Ihr Konzept unter «Auf diesem Gerät gespeichert» und klicken Sie auf «Zwischenstand speichern». Sie erhalten eine PDF.
  3. Öffnen Sie das neue Tool unter https://ebak.idibphsg.ch/, klicken Sie auf «Datei öffnen» und wählen Sie diese PDF.

Die bisherige Version wird demnächst abgeschaltet. Bitte arbeiten Sie dort nicht weiter.
