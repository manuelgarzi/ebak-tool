Bachelorarbeitskonzept erfassen

Füllen Sie Ihr Konzept direkt hier aus. Am Schluss erstellen Sie eine PDF und laden diese im Forms hoch. Ihre Eingaben bleiben auf diesem Gerät, es wird nichts ins Internet übertragen.

Ihr Browser erlaubt kein automatisches Speichern (z.B. privates Fenster). Sichern Sie Ihre Arbeit regelmässig mit «Zwischenstand speichern».

Auf diesem Gerät gespeichert

    So funktioniert es

    1. Ausfüllen. Ihre Eingaben werden laufend im Browser gespeichert. Text aus Word können Sie einfügen, fett, kursiv und Listen bleiben erhalten.
    2. Zwischenstand sichern. «Zwischenstand speichern» erstellt eine PDF, die Sie später hier wieder öffnen können, auch auf einem anderen Gerät.
    3. Einreichen. «Einreichen» prüft die Angaben und erstellt die PDF für das Forms.
    4. Überarbeiten. Die Rückmeldung der eBAK erhalten Sie als PDF. Öffnen Sie diese hier, um Ihr Konzept für den nächsten Versuch zu überarbeiten.

    Wichtig: Bearbeiten Sie Ihr Konzept nur hier im Tool. Eine PDF, die z.B. über «Drucken als PDF» neu erzeugt wurde, lässt sich nicht mehr ins Tool laden.

    Datenschutz: Das Tool läuft vollständig in Ihrem Browser. Es werden keine Daten übertragen oder auf einem Server gespeichert.
